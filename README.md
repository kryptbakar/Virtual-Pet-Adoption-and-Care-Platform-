## Overview

An interactive C++ platform for adopting and caring for virtual pets — featuring pet management, care mechanics, and an engaging user experience. Beyond core pet care it adds a **gaming center** and **social features** (adding friends, messaging) for a richer simulation.

Users can create accounts, adopt pets (**dogs, cats, or parrots**), remove pets, and interact with them through actions like **feeding, grooming, playing, and resting** — each shaping the pet's wellbeing as the session goes on.

## Features

- 👤 **Accounts** — create a user account and manage your own collection of pets
- 🐕 **Adopt & release** — add pets (dog / cat / parrot) or remove them
- 🎮 **Care mechanics** — feed, groom, play, and rest; each action drives the pet's state
- 🕹️ **Gaming center** — built-in mini-game interactions
- 💬 **Social layer** — add friends and exchange messages
- 🧾 **Menu-driven UX** — a guided text interface for every action

## Tech & Concepts

- **Language:** C++ (console application)
- **Paradigm:** Object-Oriented Programming — classes modelling users and pet types (dog / cat / parrot) with encapsulated state and behaviour
- **Interface:** text-based CLI menu system

## Build & Run

```bash
# Compile with any C++17 toolchain
g++ -std=c++17 "Virtual Pet Adoption Platform.cpp" -o vpap

# Run
./vpap        # Linux / macOS
vpap.exe      # Windows
```
