Virtual Pet Adoption & Care Platform

Adopt a dog, cat, or parrot, then feed, groom, play, and rest them into happiness — all from a friendly text menu in your terminal.

C++17 OOP CLI 2023 · Academic Project

🐾 About

This is a console-based virtual-pet simulator written in C++. Users create an account, adopt pets — dogs, cats, or parrots — and keep them happy through everyday care actions like feeding, grooming, playing, and resting. Beyond core pet care, the platform layers in a built-in gaming center and a lightweight social system, so players can add friends and exchange messages while they raise their pets.

It was built as an academic project for the BS Cyber Security program at GIKI, using object-oriented C++ to model users and pet types with encapsulated state and behaviour, all driven by a guided text-based menu.

✨ Features

  • 👤 Accounts — create a user account and manage your own collection of pets
  • 🐕 Adopt & release — add pets (dog / cat / parrot) or remove them
  • 🎮 Care mechanics — feed, groom, play, and rest; each action shapes the pet's state
  • 🕹️ Gaming center — built-in mini-game interactions
  • 💬 Social layer — add friends and exchange messages
  • 🧾 Menu-driven UX — a guided text interface for every action

🛠️ Tech Stack
